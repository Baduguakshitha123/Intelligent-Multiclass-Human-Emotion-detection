## Intelligent Text Analysis System for Multiclass Human Emotion Detection

**Transformer-Based NLP System using DistilBERT for Large-Scale Emotion Classification**

## Description

This project presents a Transformer-based Natural Language Processing (NLP) system that classifies textual data into eight emotion categories using DistilBERT. The system includes an end-to-end machine learning pipeline covering data preprocessing, class balancing, model training, evaluation, and emotion prediction.

## Key Achievements

* Processed **211,225+ raw text samples**
* Built an **8-class emotion classification system**
* Cleaned and transformed data into a balanced dataset of **160,648 samples**
* Fine-tuned **DistilBERT** using PyTorch and Hugging Face Transformers
* Achieved **87.51% Test Accuracy**
* Achieved **87.10% Weighted F1 Score**
* Achieved **93.70% Training Accuracy**

## Emotion Classes

* Anger
* Disgust
* Fear
* Negative Mixed
* Neutral
* Positive
* Sadness
* Surprise

## System Architecture

Raw Dataset → Data Cleaning → Text Preprocessing → Label Mapping → Class Balancing → Train/Validation/Test Split → DistilBERT Fine-Tuning → Evaluation → Emotion Prediction
